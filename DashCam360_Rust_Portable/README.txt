============================================================
DashCam360 Native - 汽車環景魚眼校正與 3D 空間動態投影 (Rust 原生可攜版)
============================================================

本應用程式使用 100% 純原生 Rust 打造，無任何網頁或瀏覽器核心！
具備極致效能、記憶體超低占用、真正綠色免安裝，隨插即用。

【檔案內容】
1. DashCam360.exe  - 核心主程式 (純原生 3D 渲染與 GUI，僅不到 4MB，秒開！)
2. ffmpeg.exe      - 隨附內建的高效魚眼畸變校正與視訊裁切處理引擎
3. ffprobe.exe     - 隨附視訊規格解析引擎
4. sample_videos/  - 內建 4 分割魚眼測試示範影片

【使用說明】
1. 直接雙擊『DashCam360.exe』即可啟動！
2. 點擊右側面板「選取本地檔案」（或點擊「🎲 產生測試樣品」快速體驗）。
3. 確認 4 象限的相機方位對應（左上、右上、左下、右下）。
4. 點擊「🚀 一鍵自動裁切與 v360 魚眼校正」。
5. 校正完成後，4 路影像將自動作為動態材質貼附在 3D 車身四周：
   - 滑鼠左鍵拖曳：360° 自由環視旋轉
   - 滑鼠滾輪：平滑縮放畫面
   - 滑鼠右鍵拖曳：平移視角
   - 頂部按鈕：一鍵切換鳥瞰、車前、車後、車左、車右等視角
   - 底部時間軸：同步播放、暫停與進度控制

【可攜性 (Portable)】
您可以將『DashCam360_Rust_Portable』整個資料夾複製到隨身碟，
在任何 Windows 10/11 電腦上隨插即用，無須安裝 Python、Rust、VC++ 或任何軟體！
